## 11 — 会话持久化与恢复

- 日期：2026-09-27
- 交互会话默认保存为用户本地状态目录中的追加式 JSONL 事件日志；普通单次任务保持不落盘，并提供 `--no-persist` 临时关闭保存。
- 新增 `--continue` 恢复当前工作区最近会话，以及 `--resume SESSION_ID` 精确恢复；恢复选项自动进入交互模式，并允许携带首个问题。
- 会话使用 UUID 标识并绑定规范化后的工作区路径；同一会话通过进程锁禁止并发写入，过期锁可在进程异常退出后回收。
- 用户消息、模型消息在进入历史时立即刷盘；工具调用在执行前保存，每个工具结果在完成后单独保存，恢复历史不会经过工具执行入口。
- 异常退出留下的未完成工具调用会补齐错误结果，明确提示可能存在部分副作用且不会自动重放；部分完成的多工具批次保留已有结果，只修复缺失调用。
- 日志采用严格版本、顺序和内容结构校验；可安全截断最后一条未完整写入的记录，中间损坏、未知事件或工作区不匹配会拒绝恢复。
- 会话日志不保存 API 密钥、环境变量或权限回答；README 说明日志可能包含对话、源码片段和命令输出，以及各平台默认存储位置。
- 增加会话往返、Unicode、最近会话、指定恢复、工作区隔离、并发锁、损坏日志尾部、未完成工具修复、禁用持久化和单次任务不落盘测试。

## 15 — 模型请求重试策略

- 日期：2026-09-27
- 为连接失败、请求超时、HTTP 429、500、502、503、504 和 529 添加有限重试；默认重试 2 次，使用 0.5 秒起始的指数退避。
- 新增 `--request-retries`（0—10）和 `--retry-delay`；无效、负数或非有限值在网络请求前拒绝。
- Anthropic SDK 内建重试继续设为 0，由单一运行时策略负责尝试次数和错误映射，最终错误不暴露服务端响应正文。
- 401、403、404 和其他确定性 4xx 不重试；流式响应在尚未产生可见文本时允许恢复，一旦文本已显示则明确失败而不重试，避免重复输出。
- 重试边界仅包含模型 HTTP 请求，不包含 Agent 工具调度，因此已执行的文件编辑、命令及其他工具不会自动重跑。
- 增加所有可恢复状态、退避序列、不可恢复错误、流开始前恢复、流显示后禁止重试和配置边界测试。
- 验证结果：provider、config、Agent 和 CLI 的 101 项相关测试全部通过；Ruff 格式和静态检查通过。
