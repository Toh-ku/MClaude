## 03 — 最小 Agent 循环

- 日期：2026-09-27
- 新增 Agent 循环，在单次任务中保留用户消息、模型内容块、工具调用与工具结果，直到模型正常回答。
- 接入 Anthropic 结构化工具调用，当前仅提供 `read_file`；同一模型响应中的多个调用按出现顺序执行，并按调用 ID 一次性回传。
- `read_file` 仅允许读取当前工作目录内的 UTF-8 普通文件；拒绝目录穿越与工作区外路径，缺失文件、非法参数和读取失败作为工具错误返回模型。
- 单个文件结果限制为 100,000 字符，默认最多发起 8 次模型请求；文件截断会写入结果标记，循环耗尽会明确失败。
- 区分正常结束、模型输出截断、异常停止、空响应、请求失败和循环超限；模型输出截断时保留已有文本并返回非零退出码。
- CLI 新增 `--max-iterations`，README 更新为 Agent 用法和边界说明。
- 验证结果：`uv run ruff format --check .`、`uv run ruff check .` 和 `uv run pytest` 全部通过，共 49 项测试。
- 验收限制：自动化测试已覆盖完整工具闭环；真实 API 调用仍需有效的 `ANTHROPIC_API_KEY` 与 `ANTHROPIC_MODEL`。

## 04 — 工作区搜索

- 日期：2026-09-27
- 新增 `find_files` 工具，使用 `pathspec` 匹配 git 风格 glob 模式并递归发现工作区文件；结果按路径稳定排序，默认最多返回 200 项并明确标记截断。
- 新增 `search_text` 工具，支持普通文本与正则表达式、大小写控制，以及限定单个文件或目录的搜索范围；结果包含相对路径、行号和匹配行。
- 搜索默认跳过 `.git` 元数据目录、目录符号链接和指向工作区外的文件链接；不可读取、非 UTF-8 及超过 1 MB 的文件会被跳过。
- 限制文本搜索结果为 200 项、单行展示为 500 字符，避免大型工作区输出无限增长。
- 将两个搜索工具接入 Agent 循环；同一模型响应中的搜索调用仍按顺序执行，并按调用 ID 回传结果或参数错误。
- 更新 README 与实施计划，说明当前搜索能力、工作区边界和输出上限。
- 验证结果：`ruff format --check .`、`ruff check .` 全部通过；`pytest` 的 57 项测试全部通过。

## 05 — 工具权限入口

- 日期：2026-09-27
- 新增统一工具权限入口，在每次工具执行前解析允许、询问和拒绝三种策略结果。
- 当前 `read_file`、`find_files` 和 `search_text` 三个已知只读工具默认允许，未知工具默认拒绝。
- 询问策略通过终端展示工具名称、原因和参数；用户未明确同意时拒绝执行。
- 权限策略异常、询问不可用或无效响应均采用默认拒绝；拒绝原因作为带错误标记的工具结果回传模型。
- 添加权限策略解析及 Agent 拒绝短路测试，验证被拒工具不会进入执行函数。
- 验证结果：`ruff format --check .`、`ruff check .` 全部通过；`pytest` 的 65 项测试全部通过。

## 07 — 命令执行工具

- 日期：2026-09-27
- 新增 `run_command`，使用 shell 在工作区或指定的工作区子目录中执行开发命令。
- 命令执行逐次通过权限入口询问；当前工作目录边界不作为操作系统沙箱，并在 README 中明确说明。

- 添加命令成功与失败、工作目录、超时、部分输出、结果截断、输入边界、权限策略及 Agent 调度测试。

## 08 — 终端多轮对话

- 日期：2026-09-27
- 在终端无参数启动时进入交互会话；新增 `-i` / `--interactive`，支持从命令行首个问题开始继续对话。保留传入问题后的单次运行，以及无参数管道输入时显示帮助的行为。
- Agent 支持共享内存消息历史，保留用户输入、最终回答、工具调用与结果，用户可以继续追问、修正要求；每轮单独计算模型请求上限。
- 空行不调用模型，支持 `/exit`、`/quit` 与 EOF 退出；Ctrl+C 仍退出整个程序并返回 `130`，当前轮取消留到第 10 步实现。
- 请求失败、循环超限或截断后允许继续提问；已完成的工具结果保留且不会自动重放，截断时仅保存可用文本，避免未完成工具调用进入后续上下文。
- 工具权限逐次询问，授权输入与对话输入分开处理；回答写入标准输出，提示与错误写入标准错误。会话中发生过请求错误、超限或截断时，正常退出码为 `1`。
- 增加多轮上下文、工具结果保留、失败恢复、请求预算重置、会话隔离、截断保护、授权输入、退出与中断测试，并使用模拟 HTTP 传输验证真实 SDK 收到完整多轮历史。
- 验证结果：通过 uv 运行 `ruff format --check .`、`ruff check .` 与 `pytest`，全部通过，共 96 项测试；`git diff --check` 通过。测试使用本地离线依赖；pytest 因沙箱临时目录权限限制，在授权后于沙箱外执行。
- 验收限制：本次通过模拟模型和 SDK HTTP 传输验证多轮对话，未发起真实 API 请求。
